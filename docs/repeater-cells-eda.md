# Repeater cell EDA validation

The [generated cell report](repeater-cells.md) and
[canonical view manifest](../views/repeater-buffers/manifest.json) are preserved
from the original guarded-buffer admission. Those views are generated by
[cell_views.py](../redstone_pdk/cell_views.py).

Historical EDA evidence is retained in the optional bundle under
`validation/cell-eda/`; the checker source is
[check_cell_eda.py](../tools/check_cell_eda.py). Restore the bundle and run
`python pdk.py validate` to reanalyze the original measurements and verify
the recorded implementation and artifact hashes.

The historical view manifest hashes generated LF text; some original files
were stored with CRLF. The repository preserves those bytes, and project
validation checks both the generated content and the EDA evidence hashes.
See [testing.md](testing.md) for archive restoration and
[toolchains.md](toolchains.md) for the current RTL flow.
